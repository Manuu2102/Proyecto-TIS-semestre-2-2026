# Sistema de Gestión de Edificio

Sistema destinado a la gestión de las operaciones administrativas
y servicios de un edificio.

## Proyecto

Proyecto académico de Ingeniería de Sistemas.

## Tecnologías

- Git
- GitHub
- Docker
- GitHub Actions
- DigitalOcean
- PostgreSQL
- Node.js
- Next.js
- React
- Postman  

## Estructura

- `/frontend`: aplicación frontend
- `/backend`: API y lógica de negocio
- `/docker`: archivos relacionados con contenedores
- `/docs`: documentación técnica
- `/.github/workflows`: automatización CI/CD

## Estrategia de ramas

Se utilizará una estrategia Git Flow simplificada:

- `main`: versión estable/producción
- `develop`: integración de funcionalidades
- `feature/*`: desarrollo de nuevas funcionalidades
